Nguồn dữ liệu

Lab 10 gốc dùng http://www.randyconnolly.com/funwebdev/services/travel/cities.php. URL HTTP trả JSON khi kiểm tra nhưng không thể gọi từ trang GitHub Pages HTTPS vì mixed content; URL HTTPS gặp lỗi chứng chỉ hết hạn ngày 17/11/2026. Luồng chính dùng GET tới ../data/cities.json cùng origin. Dữ liệu này là JSON mẫu tĩnh có trường name, không phải response live của endpoint; nút thử endpoint HTTPS có fallback local.

Cần mở trang qua GitHub Pages hoặc máy chủ local để request JSON chạy; file:// có thể bị chặn.
