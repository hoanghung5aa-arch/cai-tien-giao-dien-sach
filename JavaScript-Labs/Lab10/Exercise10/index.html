Exercise 10.10

jqXHR handling

Dùng object jqXHR trả về từ $.get() để xử lý thành công, lỗi và thao tác luôn chạy sau request.

Thử request và fallback

Chưa gửi request.

Loader được hiện trước request và ẩn trong .always(). Trên máy chủ local HTTP, nút thử gọi endpoint live trong tài liệu; trên Pages HTTPS, trình duyệt chặn URL HTTP nên luồng dự phòng dùng JSON mẫu cùng origin.

Kết quả thành phố

Danh sách thành phố sẽ hiện ở đây.

Nguồn dữ liệu

Lab 10 gốc dùng http://www.randyconnolly.com/funwebdev/services/travel/cities.php. Trên máy chủ local HTTP, nút thử gọi trực tiếp URL này; response live là mảng object có trường name. Trên GitHub Pages HTTPS, trình duyệt chặn mixed content nên luồng chính dùng GET tới ../data/cities.json. JSON cùng origin là dữ liệu mẫu tĩnh, không phải response live; nút thử HTTPS có fallback local.

Cần mở trang qua GitHub Pages hoặc máy chủ local để request JSON chạy; file:// có thể bị chặn.
