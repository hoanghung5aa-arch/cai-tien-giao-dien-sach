jqXHR handling

Dùng object jqXHR trả về từ $.get() để xử lý thành công, lỗi và thao tác luôn chạy sau request.

Thử request và fallback

Chưa gửi request.

Loader được hiện trước request và ẩn trong .always(). Nếu thử endpoint tài liệu bị lỗi, trang tải JSON local dự phòng rồi mới ẩn loader.

Nguồn dữ liệu

Lab 10 gốc dùng http://www.randyconnolly.com/funwebdev/services/travel/cities.php. Trang này dùng GET tới ../data/cities.json cùng origin làm luồng chính; dữ liệu mẫu giữ cấu trúc mảng có trường name, không đại diện cho response live của endpoint. Nút thử endpoint dùng HTTPS để tránh mixed content và có fallback local.

Cần mở trang qua GitHub Pages hoặc máy chủ local để request JSON chạy; file:// có thể bị chặn.
