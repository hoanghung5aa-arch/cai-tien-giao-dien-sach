Ghi chú

Request và dữ liệu demo

Tài liệu Lab 10 (2017) minh họa dịch vụ http://www.randyconnolly.com/funwebdev/services/travel/cities.php. Trình duyệt có thể chặn HTTP khi trang được phục vụ qua HTTPS, hoặc dịch vụ có thể không còn cho phép request từ website khác. Vì vậy, Exercise 10.9 và 10.10 dùng GET tới data/cities.json cùng origin làm luồng chính. JSON có trường name giống dạng dữ liệu mà tài liệu dùng; nút thử endpoint gốc sẽ tự chuyển sang dữ liệu local nếu request lỗi.

Mở trang qua GitHub Pages hoặc máy chủ local để request JSON hoạt động; mở trực tiếp bằng file:// có thể bị trình duyệt chặn.
