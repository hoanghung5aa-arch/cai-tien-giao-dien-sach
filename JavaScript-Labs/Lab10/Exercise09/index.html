Nguồn và cách chạy

Tài liệu Lab 10 minh họa http://www.randyconnolly.com/funwebdev/services/travel/cities.php, response được đọc theo dạng mảng có trường name. Trang này dùng JSON mẫu cùng cấu trúc để GET ổn định trên GitHub Pages HTTPS; đó không phải response live của dịch vụ cũ.

Mở qua GitHub Pages hoặc máy chủ local, không mở bằng file://, vì browser có thể chặn AJAX trên file tĩnh.
