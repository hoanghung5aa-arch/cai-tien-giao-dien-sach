Exercise 10.9

GET requests

Gửi GET request, đọc mảng JSON và dùng $.each() để đưa tên thành phố vào danh sách.

Gửi request

Chưa gửi request.

Trên máy chủ local chạy HTTP, nút thử gọi đúng URL cities.php trong tài liệu. Trên GitHub Pages HTTPS, trình duyệt chặn URL HTTP vì mixed content; trang thử URL HTTPS rồi chuyển sang JSON mẫu cùng origin nếu endpoint không truy cập được.

Kết quả

Danh sách thành phố sẽ hiện ở đây.

Nguồn và cách chạy

Tài liệu Lab 10 minh họa http://www.randyconnolly.com/funwebdev/services/travel/cities.php, response được đọc theo dạng mảng có trường name. Trên máy chủ local HTTP, nút thử gọi trực tiếp endpoint và nhận dữ liệu live. Trên GitHub Pages HTTPS, trang dùng JSON mẫu cùng origin vì trình duyệt chặn request HTTP hỗn hợp; nút thử HTTPS có fallback nếu chứng chỉ endpoint chưa hợp lệ. Dữ liệu JSON local là mẫu tĩnh, không phải response live.

Mở qua GitHub Pages hoặc máy chủ local, không mở bằng file://, vì browser có thể chặn AJAX trên file tĩnh.
