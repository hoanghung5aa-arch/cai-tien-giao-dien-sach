Exercise 10.9

GET requests

Gửi GET request, đọc mảng JSON và dùng $.each() để đưa tên thành phố vào danh sách.

Gửi request

Chưa gửi request.

Luồng chính đọc ../data/cities.json cùng origin. URL HTTP trong tài liệu hiện trả JSON nhưng bị mixed content trên GitHub Pages HTTPS; URL HTTPS gặp lỗi chứng chỉ hết hạn khi kiểm tra ngày 17/11/2026. Nút thử endpoint dùng URL HTTPS và tự chuyển sang JSON mẫu local nếu request lỗi.

Kết quả

Danh sách thành phố sẽ hiện ở đây.

Nguồn và cách chạy

Tài liệu Lab 10 minh họa http://www.randyconnolly.com/funwebdev/services/travel/cities.php, response được đọc theo dạng mảng có trường name. Lần kiểm tra ngày 17/11/2026, URL HTTP trả JSON nhưng HTTPS không kết nối được do chứng chỉ hết hạn. Trang dùng JSON mẫu cùng cấu trúc để GET ổn định trên GitHub Pages; dữ liệu này không phải response live. Nút thử endpoint có fallback khi request lỗi.

Mở qua GitHub Pages hoặc máy chủ local, không mở bằng file://, vì browser có thể chặn AJAX trên file tĩnh.
