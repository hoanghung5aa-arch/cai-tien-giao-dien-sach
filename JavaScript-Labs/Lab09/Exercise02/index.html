Exercise 9.2

DOM Family Relations

Em xem quan hệ giữa parent, child và sibling; các khoảng trắng trong HTML cũng tạo thành text node.

Vùng nội dung (id=first)

Node 1

Đây là thẻ con đầu tiên.

Node 2

Đây là thẻ con thứ hai.

Node 3

Đây là thẻ con thứ ba.

Trong vòng lặp dưới đây, childNodes bao gồm cả các text node do xuống dòng và thụt lề.

Quan sát cây DOM

Gợi ý: mở Console để xem nodeType. nodeType = 3 là text node; nodeType = 1 là phần tử HTML.
