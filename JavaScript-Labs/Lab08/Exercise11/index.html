Exercise 8.11

Arrays of Objects

Duyệt mảng quốc gia, thử nhiều cách truy cập property và dựng card bằng for..in.

Chọn cách đọc thuộc tính name

Vòng lặp thuộc tính

Mỗi thẻ dưới đây dùng vòng lặp for..in và bracket notation để xuất từng cặp tên/giá trị, gồm cả mã ISO dùng để chọn cờ.

for (var i = 0; i < countries.length; i++) {
  var c = countries[i];
  for (var propertyName in c) {
    document.write(propertyName + ": ");
    document.write(c[propertyName]);
  }
}

Ba nút phía trên lần lượt đọc countries[i].name, c["name"] và c[temp] với temp = "name".
