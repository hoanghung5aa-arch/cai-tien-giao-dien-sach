Lab 08 · JavaScript 1

Language Foundations

Thực hành cách đưa JavaScript vào HTML, cú pháp nền tảng, hàm, mảng và object. Mỗi trang bên dưới có ví dụ chạy được và ghi chú để tự kiểm tra theo hướng dẫn Lab 08.

Portfolio / Lab 08

Mục tiêu thực hành

  • Liên kết JavaScript với HTML theo dạng nhúng và file ngoài.
  • Làm quen với biến, kiểu dữ liệu, điều kiện, vòng lặp và Browser Console.
  • Thực hành hàm, phạm vi biến, mảng và object.

Lưu ý: Exercise 8.1 và 8.4 cần thao tác trực tiếp trong cài đặt trình duyệt; trang web không thể tự bật/tắt JavaScript.
