  1. Hàm ngoài taxRate() được gọi bởi calculateTax(amount) và calculateTotal(price, quantity).
  2. Chuyển taxRate() thành named nested function.
  3. Gán named function expression cho biến tax, gọi tax().
  4. Bỏ tên hàm để tạo anonymous function expression.
  5. Cuối cùng truyền anonymous function như tham số tax vào calculateTax.
function calculateTax(amount, tax) {
  return amount * tax();
}
function calculateTotal(price, quantity) {
  var amount = price * quantity;
  return amount + calculateTax(amount, function () {
    return isCanadian ? 0.05 : 0.0;
  });
}
