Embedded JavaScript

JavaScript được nhúng trong HTML và hiển thị alert ngay khi trang tải, như hướng dẫn Lab.

Script trong phần head

Phần alert trong mã nguồn nằm trực tiếp giữa thẻ script ở head; file JS ngoài chỉ phục vụ nút gọi lại.
