Exercise 8.5

Using the Browser Console

Theo dõi lỗi, đọc biến và dùng log/warn/error.

Thực hành Browser Console

  1. Mở DevTools (thường F12 hoặc Ctrl+Shift+I), chọn Console.
  2. Trong bản mẫu, đổi tạm document thành doccumment, tải lại, đọc ReferenceError rồi sửa chính tả.
  3. Nhập lần lượt count, output, var temp = count * 7, temp. Kết quả dự kiến: 2, chuỗi, undefined, 14.
  4. Quan sát log, warning và error khi trang tải.

Không để lỗi chính tả trong mã đang chạy để trang vẫn hoạt động.

Biến toàn cục thử trong console

count = 2
output = "JavaScript Console"
temp = count * 7
