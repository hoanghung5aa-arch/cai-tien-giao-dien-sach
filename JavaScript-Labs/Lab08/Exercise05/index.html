Exercise 8.5

Using the Browser Console

Sắp xếp file ngoài vào thư mục js, tạo và sửa lỗi, rồi đọc giá trị biến trong console.

Các bước thực hành theo Lab

  1. File hello.js đã được đặt trong thư mục js/; trang đang liên kết bằng src="js/hello.js".
  2. Trong editor, tạm đổi document ở dòng document.write(...) thành doccumment, lưu và tải lại. Mở Console để đọc lỗi “doccumment is not defined”.
  3. Sửa lại thành document, lưu và tải lại để nội dung hiện lại. Mã hiện tại đang ở dạng đúng để trang hoạt động.
  4. Mở DevTools bằng F12 hoặc Ctrl+Shift+I, chọn Console. Firefox có thể mở Web Console từ menu Web Developer.
  5. Nhập lần lượt count, output, var temp = count * 7, rồi temp. Kết quả dự kiến: 2, "<br>Count = 2", undefined, 14.
  6. Quan sát các dòng log, warning và error từ script trong head. Dùng nút dưới đây nếu muốn tạo một ReferenceError độc lập để tập đọc Console.

Chưa chạy mô phỏng lỗi.

Nút chỉ tạo lỗi trong một lần bấm. Để hoàn thành đúng bước PDF, hãy tự sửa rồi khôi phục dòng trong file js/hello.js.

File ngoài hiện tại: js/hello.js

document.write("this text was written from JS");
var count = 1;
document.write("<br>Count = " + count);
count++;
var output = "<br>Count = " + count;
document.write(output);
