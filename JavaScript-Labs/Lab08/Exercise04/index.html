Exercise 8.4

Using NoScript

Dùng noscript khi JavaScript bị tắt.

Thẻ noscript

Trình duyệt chỉ hiển thị nội dung trong <noscript> khi JavaScript bị tắt hoặc không được hỗ trợ.

  1. Mở trang trong một tab.
  2. Tắt JavaScript trong cài đặt trình duyệt.
  3. Tải lại trang và xem dòng fallback bên phải.
  4. Bật JavaScript trở lại.
Cần tắt JavaScript thật rồi tải lại; ẩn phần tử bằng CSS không kiểm tra được noscript.
