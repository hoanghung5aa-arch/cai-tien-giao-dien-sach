Exercise 8.8

JavaScript Functions

Đi từ hàm tự xuất nội dung đến hàm trả về chuỗi, nhận tham số và minh họa scope.

Chạy từng phiên bản

Xem dạng document.write trong hướng dẫn 
function outputBox() {
  document.write("<div class='movingDiv' id='div1'>");
  document.write("This is div 1");
  document.write("</div>");
}
outputBox();

Bản demo dùng DOM để nút có thể chạy sau khi trang đã tải; nội dung và trình tự hàm tương ứng ví dụ trong PDF.

Global và local scope

boxClass nằm ngoài hàm. Trong outputBox(num), box dùng var nên chỉ tồn tại trong hàm.

Chưa kiểm tra scope.

Xem hai khai báo scope 
var boxClass = "movingDiv"; // global

function outputBox(num) {
  var box = "...";           // local
  return box;
}

// Thử nghiệm trong bản thứ hai:
function outputBoxWithoutVar(num) {
  box = "...";               // tạo global ngoài ý muốn
  return box;
}

Hãy bấm thử trước và sau khi bỏ var, rồi đọc Console. Không giữ cách bỏ var trong mã chính.

Từng bước trong PDF

  1. Phiên bản đầu tiên tạo một hộp từ bên trong hàm.
  2. Đổi hàm để trả về chuỗi HTML và xuất chuỗi đó.
  3. Thêm tham số num để tên/id đổi theo số.
  4. Lặp từ 1 đến 5 để tạo năm hộp.
  5. Khai báo boxClass ở phạm vi ngoài và so sánh với biến box trong hàm.
  6. Thử đọc box ngoài hàm; sau đó chạy biến thể không có var và quan sát global.
