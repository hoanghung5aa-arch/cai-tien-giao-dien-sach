Exercise 8.10

Creating JavaScript Objects

Tạo order, gọi method, thử hai instance của constructor và so sánh dấu ngoặc gọi hàm.

Chọn cách tạo order

Method total

Chọn một cách bên trên, rồi so sánh property order.total với lời gọi order.total().

Chưa chọn cách tạo object.

Các bước được thể hiện

  1. Gán product, price, quantity và total lên object.
  2. Dùng dấu chấm rồi thử bracket notation để đọc/ghi property.
  3. Tạo object literal.
  4. Dùng constructor tạo example1 và example2.
  5. Hiển thị các property, gọi total(), rồi dùng method output() trên cả hai đơn.
Xem constructor mẫu
function Order(product, price, quantity) {
  this.product = product;
  this.price = price;
  this.quantity = quantity;
  this.total = function () { return this.price * this.quantity; };
  this.output = function () { /* xuất thông tin */ };
}
