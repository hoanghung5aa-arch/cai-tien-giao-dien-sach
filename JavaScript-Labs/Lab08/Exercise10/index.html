Exercise 8.10

Creating JavaScript Objects

Tạo order object bằng nhiều cách và thêm method.

Chọn cách tạo đối tượng

Object literal

var order = {
  product: "Self Portrait",
  price: 15, quantity: 2,
  total: function () { return this.price * this.quantity; }
};

Constructor và method

function Order(product, price, quantity) {
  this.product = product;
  this.price = price;
  this.quantity = quantity;
  this.total = function () { return this.price * this.quantity; };
}

Mỗi nút tạo order theo một cách, sau đó đọc các thuộc tính và gọi total().
