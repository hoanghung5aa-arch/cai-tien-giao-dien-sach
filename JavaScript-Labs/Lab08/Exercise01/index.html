Exercise 8.1

Enabling/Disabling JavaScript

Bật/tắt JavaScript trên trình duyệt và so sánh thông báo.

Thử bật/tắt JavaScript

Exercise cần đổi cài đặt trình duyệt rồi tải lại trang kiểm tra. Trang hiện tại không thể tự thay đổi quyền chạy JavaScript.

  1. Mở JavaScriptTest.php ↗.
  2. Khi JavaScript bật, trang báo “You have JavaScript enabled”.
  3. Tắt JavaScript trong cài đặt nội dung/site settings của trình duyệt, tải lại và ghi nhận thông báo disabled.
  4. Bật JavaScript trở lại sau khi thử xong.
Đường dẫn cài đặt khác nhau tùy trình duyệt và phiên bản. Tìm mục JavaScript trong cài đặt quyền nội dung. Nếu tắt riêng cho trang, hãy cấp quyền lại sau bài thử.

Trạng thái trang này

Cần kiểm tra cả hai trạng thái bằng cách tải lại trang sau khi đổi cài đặt.
