Heroes of JavaScript and HTML

Heroes of JavaScript and HTML is a “Heroes of Might and Magic”-like game, but for code nerds. Each hero has its unique coding abilities and based on them he can develop software applications.

Currently the game has only four hero types:

Front-end Developer

Front-end developers create user interfaces and help people use websites with ease.

Mobile Developer

Mobile developers build applications for phones and tablets.

Web Developer

Web developers create modern websites and useful online services.

QA Engineer

QA engineers test software and help make sure it works correctly.
