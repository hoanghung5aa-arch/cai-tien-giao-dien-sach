# Bài tập CSS – Buổi 3

Mở `index.html` rồi chọn mục cần xem.

## Nội dung

- CSS Diner: đã hoàn thành 32/32 level.
- CSS Speedrun: đã hoàn thành phần Intro và level 1–10.
- Mục 2: định dạng văn bản, BIT-UEH, nền BIT và xử lý tràn chữ.
- Đã chọn phương án 3b trong đề: làm mục 4, 5, 6 và 7; không làm phương án 3a.
- Mục 4–7: menu, Shared Hosting, portfolio 9 hình và bố cục wrapper.
- Mục 8a: chọn CSS1, dùng nội dung và hình ảnh từ `css1.zip`, rồi bổ sung CSS theo mô tả trong PDF.
- Mục 9: dùng biểu tượng Font Awesome trên trang chính.

## Cấu trúc

- `BaiTap1.html` đến `BaiTap6.html`: lần lượt là các mục 2, 4, 5, 6, 7 và 8a.
- `css/style.css`: các quy tắc CSS.
- `images/`: logo BIT, hình minh họa và ảnh gốc của bài CSS1 trong `images/css1/`.
- `index.html`: trang chính, thông tin sinh viên và liên kết đến các mục.

## Lưu ý trước khi nộp

- Trang chính hiển thị ảnh sinh viên từ `images/avatar.jpg`.
- Mục 8a dùng HTML và bốn ảnh hero từ gói `css1.zip`; các quy tắc CSS được viết trong `css/style.css` theo các yêu cầu của đề.
- Ảnh minh chứng CSS Diner cho đủ 32 level nằm trong `evidence/css-diner/`.
- Ảnh màn hình hoàn thành CSS Speedrun nằm trong `evidence/css-speedrun/css-speedrun-completed.png`; màn hình hiển thị Intro và Level 1–10 đã hoàn thành.
- Font Awesome tải từ CDN, cần kết nối Internet để hiện biểu tượng.
