Noto Sans, local webfont files

Source: Google Fonts, Noto Sans v42
https://fonts.google.com/noto/specimen/Noto+Sans
https://fonts.googleapis.com/css2?family=Noto+Sans:wght@400;500;600&display=swap

The Latin, Latin Extended and Vietnamese variable WOFF2 subsets are served
locally. The interface uses weights 400, 500 and 600. No visitor request to
Google Fonts is required. License: SIL Open Font License 1.1 (OFL-NotoSans.txt).

Typography polish follows the Unslop skill by Damir Sokolovsky (@heydamir),
licensed CC BY 4.0: https://github.com/heydamir/unslop
